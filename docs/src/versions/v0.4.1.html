ZAK MCP Gateway v0.4.1

11 Nov 2026 · Published on npm

The gateway becomes an npm package any project can install. No change to how it saves tokens: same meta-tools, same defaults, same results as v0.4.

In one picture: The concierge desk is now sold as a kit: every building installs its own with one command instead of copying the original.
