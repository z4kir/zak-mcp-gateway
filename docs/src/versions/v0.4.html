ZAK MCP Gateway v0.4

6 Oct 2026 · Fewer turns, cheaper turns: 7 improvements

Targets what the lean test showed: searches before writes, the fixed cost of every turn, and multi-step build jobs. All options are off by default; defaults behave exactly like v0.3.

In one picture: "The usual, please": the restaurant already knows the steps of the order and runs them all; you get one confirmation.
