3. Detailed Configuration Details

🚀 Gateway Server (Dev - tsx)
Runs directly from TypeScript sources without waiting for build steps. Ideal for active development of gateway dispatcher, discovery, or cache engines.
"name": "Gateway Server (Dev - tsx)",
"type": "node",
"request": "launch",
"runtimeArgs": ["--import", "tsx"],
"program": "${workspaceFolder}/src/cli.ts",
"args": ["--config", "${workspaceFolder}/config/servers.json"]
📦 Gateway Server (Built - dist/cli.js)
Executes the compiled JavaScript bundle. Triggers Build Gateway (tsc) pre-launch task automatically to ensure source maps match compiled code.
"name": "Gateway Server (Built - dist/cli.js)",
"type": "node",
"request": "launch",
"program": "${workspaceFolder}/dist/cli.js",
"preLaunchTask": "Build Gateway (tsc)",
"sourceMaps": true
🌐 Agent UI Server (Next.js Dev)
Starts the web UI frontend and Gemini MCP bridge at http://localhost:3000. Supports breakpoints in API routes (/api/chat).
"name": "Agent UI Server (Next.js Dev)",
"type": "node",
"request": "launch",
"cwd": "${workspaceFolder}/agent-ui",
"runtimeExecutable": "node",
"runtimeArgs": ["./node_modules/next/dist/bin/next", "dev"]
🧪 Mock MCP Server (Stdio Test)
Runs the lightweight mock server providing mock_read_db and mock_write_db without requiring external credentials.
"name": "Mock MCP Server (Stdio Test)",
"type": "node",
"request": "launch",
"program": "${workspaceFolder}/tests/mock-server.mjs"

Downstream MCP Servers

Individual launch profiles exist for each downstream server declared in config/servers.json. They include Windows platform overrides for npx.cmd to ensure smooth execution on Windows:

  • Downstream: Filesystem (MCP Server): Mounts the current repository folder.
  • Downstream: GitHub (MCP Server): Uses ${env:GITHUB_PERSONAL_ACCESS_TOKEN}.
  • Downstream: Postgres (MCP Server): Connects to local PostgreSQL instance.
  • Downstream: Slack (MCP Server): Uses ${env:SLACK_BOT_TOKEN}.

Compound Launch Configurations

Use the "Full Stack: Gateway (Dev) + Agent UI" compound launch configuration to start both the backend MCP gateway and the frontend Next.js chat agent simultaneously with a single click (F5).

4. Quick Start: Debugging in VS Code

  1. Open the Run & Debug view in VS Code (Ctrl + Shift + D).
  2. From the top dropdown, select "Full Stack: Gateway (Dev) + Agent UI" or any individual server.
  3. Press F5 to begin debugging with active breakpoints.
  4. Inspect logs in the integrated terminal or output console.
